# Flood simulator: solver choice and open global data

Objective: add the FV1/DG2 solver choice with a volume-based rule for negative depths, then improve the DG2 ROI simulator with open, global data (Earthdata first) from the report `reports/Fuentes para simulador de inundación.md`.
Branch: `feature/flood-ui-dg2`. Delivery: work-unit commits on the branch; PR slicing decided when the user asks for a PR. Runners: `pytest` (pipeline), `manage.py test` (backend, PYTHONPATH=..), `node --test` + `tsc -b` + eslint + Playwright flow check (web).

## Specs

- S1 Solver choice: "Podemos usar los 2 métodos FV1 y DG2?" → accepted design: panel selector "Método": DG2 (más preciso, default) and FV1 (estable, para terreno empinado); the method is recorded and shown in results; the thin-depth threshold only applies to DG2. Automatic fallback (L6): "si el método que eligio llega a fallar, automaticamente el programa cambia al otro método y le arroja al usuario los resultados, se le menciona al usuario que se cambio de método." Both directions; preparation/acquisition failures do not fall back; state/results carry requested_solver, solver and solver_fallback {from, to, reason}; no retry button.
- S2 Negative depths by volume (accepted): negatives are set to 0 and the added volume is measured per frame against the water in the domain: < 1 % normal result; 1–10 % result shown with a visible warning ("artefactos numéricos en terreno muy empinado; profundidades poco confiables, la dirección del flujo sí vale"); > 10 % the run fails.
- S3 "Alturas de referencia podemos usar una": one vertical datum for every height (EGM2008), with explicit conversions; Copernicus GLO-30 (`NISAR_DEM`, ASF Earthdata, ellipsoidal) as a terrain option.
- S4 Land surface: per-cell Manning from ESA WorldCover (manningfile, DG2 and FV1); runoff by Curve Number per cell (WorldCover + HYSOGs250m from ORNL DAAC Earthdata) as net rain per cell; urban areas allowed with a warning (built-up class).
- S5 Rain: IMERG run chosen by event age (Final, Late, Early); design-storm mode from an open global return-period dataset with an alternating-block hyetograph.
- S6 Coast: tide time series at the boundary (open model, e.g. EOT20) instead of only a fixed level, and open bathymetry (GEBCO) for sea cells.
- S7 Antecedent soil moisture from NISAR SME2 (Earthdata) to choose the Curve Number condition.
- S8 Constraints: "tiene que funcionar en cualquier parte del mundo"; "si son comerciales, no las podemos usar" → only openly licensed sources (no non-commercial, share-alike-NC or paid data: FABDEM, FathomDEM, MERIT Hydro, MSWEP, TPXO excluded); results keep `hydraulic_accuracy_validated: false`.
